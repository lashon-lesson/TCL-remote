# שלט TCL – אפליקציה לאנדרואיד ולאייפון 📺

אפליקציה שמתחברת ישירות לטלוויזיות TCL (Google TV / Android TV) דרך ה-WiFi, **בלי מחשב באמצע**.
העיצוב זהה לשלט, עם כפתורים ל-FreeTV ול-Cellcom tv, תמיכה בכמה טלוויזיות וחיפוש אוטומטי ברשת.

---

## שלב 1: בניית האפליקציה (פעם אחת, בלי להתקין כלום במחשב)

GitHub בונה את האפליקציה בשבילך בחינם.

1. היכנס ל-[github.com](https://github.com) (או פתח חשבון).
2. למעלה מימין: **+** ← **New repository**. שם: `tcl-remote`. סמן **Private** ← **Create repository**.
3. בדף שנפתח לחץ על **uploading an existing file**.
4. פתח את ה-ZIP במחשב, וגרור לחלון **את כל התוכן של התיקייה `tcl_remote`** (כולל התיקייה `.github`) ← **Commit changes**.
   > אם התיקייה `.github` לא מופיעה בסייר הקבצים: ב-Windows ← תצוגה ← הצג ← "פריטים מוסתרים".
5. עבור ללשונית **Actions**. הבנייה מתחילה לבד ולוקחת כ-10 דקות.
6. כשמופיע ✅ ירוק – לחץ על הריצה, ולמטה תחת **Artifacts** יופיעו:
   - `TCL-Remote-Android` ← קובץ APK לאנדרואיד
   - `TCL-Remote-iPhone` ← קובץ IPA לאייפון

אם מופיע ❌ אדום – לחץ עליו, העתק את הודעת השגיאה ושלח לי.

## שלב 2: התקנה

### אנדרואיד
1. העבר את `TCL-Remote.apk` לטלפון (וואטסאפ לעצמך, Google Drive, כבל).
2. פתח את הקובץ. אם מופיעה אזהרה – אשר "התקנה ממקורות לא ידועים".
3. זהו. האפליקציה מותקנת לתמיד. לטלפונים נוספים פשוט שלח את אותו קובץ.

### אייפון
אפל לא מאפשרת להתקין אפליקציות מחוץ ל-App Store בקלות. יש שתי דרכים:

- **חינם (Sideloadly):** מתקינים במחשב את [Sideloadly](https://sideloadly.io) ו-iTunes, מחברים את האייפון בכבל, גוררים את `TCL-Remote.ipa` ומתחברים עם ה-Apple ID שלך.
  באייפון: הגדרות ← כללי ← VPN וניהול מכשירים ← אשר את המפתח. בגרסאות iOS חדשות צריך גם להפעיל "מצב מפתח" (הגדרות ← פרטיות ואבטחה).
  ⚠️ **במסלול החינמי האפליקציה מפסיקה לעבוד אחרי 7 ימים** וצריך לחזור על ההתקנה (מעל 3 אייפונים לא נתמך).
- **בתשלום (99$ לשנה):** חשבון Apple Developer מאפשר התקנה לשנה שלמה, או הפצה דרך TestFlight למשפחה. אם תבחר בזה – אעזור לך להגדיר.

## שלב 3: חיבור הטלוויזיות

1. פתח את האפליקציה. באייפון אשר את הבקשה **"גישה לרשת מקומית"**.
2. לחץ **חפש טלוויזיות ברשת** – הטלוויזיות הדלוקות יופיעו. לחץ על אחת להוספה.
   (אפשר גם להזין IP ידנית: בטלוויזיה ← הגדרות ← רשת ואינטרנט ← הרשת המחוברת.)
3. על מסך הטלוויזיה יופיע קוד בן 6 תווים – הקלד אותו באפליקציה. מחובר.
4. כך לכל טלוויזיה. לחיצה על **TCL** למעלה מחליפה ביניהן.

כל טלפון שמשתמש בשלט צריך לעבור צימוד אחד מול כל טלוויזיה.

מומלץ לקבוע IP קבוע לכל טלוויזיה בהגדרות הנתב (DHCP Reservation), כדי שהכתובת לא תשתנה.

## FreeTV ו-Cellcom tv
בלחיצה הראשונה האפליקציה תבקש את **מזהה האפליקציה**:
חפש את האפליקציה ב-[play.google.com](https://play.google.com), ובכתובת הדף העתק את מה שאחרי `id=`.
לחיצה ארוכה על כל כפתור אפליקציה פותחת שוב את ההגדרה (אפשר גם לשנות שם ולהחליף אפליקציה).

## הערות
- **הדלקה:** כדי שהשלט ידליק טלוויזיה כבויה, הפעל בטלוויזיה "הפעלה מהירה / Quick Start" או "הפעלה דרך רשת" (הגדרות ← מערכת ← צריכת חשמל).
- **מקלדת:** אנגלית, ספרות וסימנים בסיסיים. לחיפוש בעברית השתמש ב-Search (חיפוש קולי בטלוויזיה).
- **אם הטלוויזיה "שכחה" את הטלפון** (למשל אחרי איפוס) – האפליקציה תבקש קוד חדש, או: TCL ← ⋮ ← צמד מחדש.

## מבנה הקוד
- `lib/main.dart` – מסך השלט וחלונות ההגדרה
- `lib/atv/connection.dart` – צימוד ושליטה (פרוטוקול Android TV Remote v2)
- `lib/atv/identity.dart` – יצירת מפתח ותעודה לטלפון
- `lib/atv/proto.dart`, `lib/atv/der.dart` – קידוד הודעות ותעודות
- `lib/scanner.dart` – חיפוש טלוויזיות ברשת
- `.github/workflows/build.yml` – בנייה אוטומטית לאנדרואיד ולאייפון
